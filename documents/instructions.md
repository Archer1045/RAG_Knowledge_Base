# 岗位规则

来源：instructions.txt

| 主题 | 内容 |
| --- | --- |
| 招聘岗位 | 外卖员（美团、饿了么） 又叫：外卖小哥、送餐员、外卖骑手 |
| 岗位所在城市 | 目前只限北京 |
| 工作地点 | 全北京，各个区都有，100多个站点，可以匹配候选人希望发展的商圈 |
| 性别要求 | 男 |
| 学历要求 | 没有限制的 |
| 年龄要求 | 一般是18到45周岁，有的站点最高接受到50周岁；超过50岁很难通过面试了 |
| 是否提供食宿 | 咱这个行业都不包吃的，但是咱整天跑外卖跟商家都比较熟悉了，也比较便宜；住宿可以安排的，一个月也就二三百块钱也不贵，也有骑手一起合租的都能给您安排。 |
| 住宿条件 | 住宿一般6-8人间，具体每个站点不一样 |
| 是否提供车电动车 | 站点提供电车，无押金，无需提前交，费用每月700元，从工资里扣除。 |
| 是否含社保 | 公司给上商业险，社保需自己办理，公司可以提供协助 |
| 不上社保合法吗 | 我们的劳动合同是完全合法的，里面会约定工作性质及相关事宜。条款很详细，这个面试时我具体给你解释吧。 |
| 什么是全勤奖 | 每月干满28天的额外奖励，各站点金额不等 |
| 入职条件 | 18-50周岁，无犯罪记录，无征信逾期，会骑电动车看导航，有健康证就可以了！ |
| 面试时间 | 随时可以安排 |
| 新人培训 | 都有新人培训，或者老带新，一般一两天就能上手了 |
| 新人顾虑 | 不会给新人派远单，也不会扣新人钱，工作氛围很好的 |
| 入职押金 | 没有押金、0元入职、我们是站点直招 |
| 路线好跑吗 | 好跑、路不熟的话有人带 |
| 取餐容易吗 | 非常简单，咱们系统自带导航，而且有群找不到随时有人告诉你的 |
| 站点有多少人 | 这个不一定、每个站点规模、不同季节都不一样 |
| 单太多跑不完 | 不会有这种情况，系统派单自动调配的 |
| 做不满一个月有工资吗 | 跑的每一单都是有钱哒 |
| 驾驶证 | 电动车不用驾驶证的 |
| 薪资水平 | 平均8000-16000每月，按送单数阶梯结算，多劳多得 |
| 新人首月薪资水平 | 新人一般7000-9000之间，但很快就跑熟了，都比这个高 |
| 单价 | 北京这边是7-15元，月单量越高，单价越高 |
| 是否提供工装、装备 | 如果站点有旧的，可以免费拿去用，如果买新的，可以先用，后在工资中扣除 |
| 全职出勤要求 | 建议每天在线时长超过8小时，具体排班时间听站长安排 |
| 是否接受兼职 | 不接受 |
| 发薪日 | 每月20号 |
| 需携带证件 | 身份证、银行卡、健康证 |
| 健康证办理 | 需要办，但不着急，入职时站点可以协助办理 |
| 面试多久能入职 | 站点面试通过，当天就可入职 |
| 视频面试 | 需要到站点线下面试哦 |
| 电动车换电费 | 需要自行支付 |
| 一天能送多少单 | 新手每天30单以上，老骑手四五十单 |
| 离职提前通知 | 需要提前45天跟站点报备哦 |
| 最短可以干多久 | 建议干满1-2周适应一下。如果想换工作，还可以找我们，我们帮你找 |
| 超时罚款吗 | 不扣、不扣 |
| 节假日休息吗 | 法定节假日可以休息，但留岗有额外补贴哦 |
| 预支工资 | 可预支。具体来站点问下站长，因为每个站点政策都不一样 |
| 下雨天必须跑吗 | 下雨天最赚钱啦，距离又近价格又高额外补助也多 |
| 能否周结或日结 | 周结日结缺口不大而且单价也低一些的，可以尽量帮你找 |
| 专送和众包的区别 | 专送单子多，距离近，单量有保障，超时不扣款，出问题有人帮忙处理；众包几乎没什么好单了，还需要自己买车 |
| 应聘方式 | 去站点进行面试，面试通过后即可上岗 |
